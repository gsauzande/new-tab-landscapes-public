## GitHub Pages Deployment Setup

To activate GitHub Pages for this repository:
1. Go to **Settings** > **Pages** in the GitHub repository (`gsauzande/new-tab-landscapes-public`).
2. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` / `/ (root)`
3. Click **Save**.
4. Once deployed, the privacy policy will be live at `https://gsauzande.github.io/new-tab-landscapes-public/`.
